## Response Section

### ข้อดี
* เพิ่มความเร็วในการ Query
* ลดการทำงาน I/O ของ Disk
* เพิ่มประสิทธิภาพการ Sorting และ Grouping
* ป้องกันการมีข้อมูลซ้ำ

### ข้อเสีย
* ใช้พื้นที่จัดเก็บข้อมูลเพิ่มขึ้น
* การทำงานที่ช้าลงเพราะ Index ต้องมีการเปลี่ยนแปลงตลอดเวลา (เห็นชัดกับ Database ขนาดใหญ่)
* ไม่มีประสิทธิภาพในการทำงานหากทำ Indexing ผิดวิธี
